# Logic Building Assignment 1

Author: Arvind Madhav Baile
Date: 22/10/2026
Language: C

## Programs
1. `program1_1.c` — Divide two integers, with division-by-zero handling.
2. `program1_2.c` — Print `Marvellous` five times.
3. `program1_3.c` — Print numbers from 5 down to 1.
4. `program1_4.c` — Check whether an integer is divisible by 5.
5. `program1_5.c` — Print five asterisks.

## Compile and run on Ubuntu
From this folder, compile and run each program separately:

```bash
gcc program1_1.c -o program1_1 && ./program1_1
gcc program1_2.c -o program1_2 && ./program1_2
gcc program1_3.c -o program1_3 && ./program1_3
gcc program1_4.c -o program1_4 && ./program1_4
gcc program1_5.c -o program1_5 && ./program1_5
```
