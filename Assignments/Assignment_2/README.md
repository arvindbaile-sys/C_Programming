## Programs
1. `program2_1.c` — Print N asterisks using an incrementing counter.
2. `program2_2.c` — Print N asterisks using a decrementing counter.
3. `program2_3.c` — Print `Hello` if the number is less than 10; otherwise `Demo`.
4. `program2_4.c` — Print a number according to the given frequency.
5. `program2_5.c` — Check whether a number is even or odd.

## Compile and run on Ubuntu
```bash
gcc program2_1.c -o program2_1 && ./program2_1
gcc program2_2.c -o program2_2 && ./program2_2
gcc program2_3.c -o program2_3 && ./program2_3
gcc program2_4.c -o program2_4 && ./program2_4
gcc program2_5.c -o program2_5 && ./program2_5
```
